Home Page

It should include: 
logo- Done

welcome message- Done

About Us Page

This may include;
history of JCDA- Done
vision- Done
mission- Done
values- Done

The content should be organized clearly using headings, sections, images or placeholders, and suitable

Events Page
The Events page should present upcoming community events using event cards or another suitable
layout. 
Each event should include
event title - Done
date - Done
location- Done
category- Done
